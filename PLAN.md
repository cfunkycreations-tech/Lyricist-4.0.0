## 2. Lyric video cut to the beat (Kaggle)

Done looks like: pick a finished take, press **Make the video**, and get back:

- a 16:9 lyric video: pictures change on the downbeats, words light up as sung
- vertical 9:16 chorus clips for Shorts, Reels and TikTok
- `.lrc` and `.srt` synced-lyric files

How, on the same upload, run and collect path the songs use, with its own saved
models (like the music model cache):

1. Notebook: word timings from the song (WhisperX), beats and downbeats, one
   picture per section from the song's tags (a fast image model on the T4s),
   then ffmpeg cuts it all together. Tested offline with fakes first, like
   `scripts/kaggle-takes-check.py`.
2. `kaggleCloud.js`: a `renderVideo` next to `render`, with the same push,
   poll, collect and model cache.
3. A button on the take in Black Hole Studios. Videos land next to the songs.
4. A Ghost action, `make_the_video`, so a job can finish a song all the way.

Where it stands (branch `claude/lyric-video`, local, stacked on PR #35):
- Done: `resources/kaggle-lyric-video.ipynb`, generated by
  `scripts/make-video-notebook.py`. It uses demucs 4.1 (apply_model, soundfile
  I/O), stable-ts 2.19.1 `align(original_split=True)`, librosa downbeats, SDXL
  base `from_single_file` on both T4s, and ffmpeg (ASS `\kf` karaoke) to build
  the 16:9 video, 9:16 chorus clips, `.lrc` and `.srt`.
- Next:
  - `scripts/kaggle-video-check.py`: run the real cells with fake torch,
    stable_whisper and diffusers on a click track at 120 BPM (downbeats
    0.25 + 2k s, 60 s). Check 1920×1080 / 1080×1920, durations, cuts on
    downbeats (ffmpeg scene detect), LRC equal to the fake timings, and `{}\`
    in lyrics.
  - `kaggleCloud.js`:
    - upload: `blobs.BlobApiService/StartBlobUpload` {type:'DATASET', name,
      contentLength, lastModifiedEpochSeconds}, then PUT the bytes to
      createUrl, then the token;
    - dataset `lyricist-video-song`: CreateDataset (licence
      'copyright-authors', falling back to 'CC0-1.0') or CreateDatasetVersion
      {body:{deleteOldVersions:true, files:[{token}]}};
    - poll ListDatasetFiles until the new name is listed and GetDatasetStatus
      says READY;
    - push `lyricist-lyric-video` with `datasetDataSources`;
    - generalise `modelCache` into a spec (video cache
      `lyricist-video-models`: SDXL single file + medium.pt, matched by path
      suffix);
    - stream the downloads to disk;
    - `explainFailure(slug)`;
    - `collect()` also fetches the video's outputs.
  - `main.js`: a `kaggle-video` IPC with its own progress job and stop flag;
    only files inside songsDir, and bytes are written there first when a take
    has no file; a recipe sidecar `.recipe.json` so takes brought in from disk
    keep their own lyrics.
  - Black Hole Studios: a Make the video button per take. The Ghost
    `make_the_video` action returns at once; add it to Sly's UNCHECKABLE list,
    `ACTION_TAB`, the GhostService docs, ghostHands, and the claims regex.
  - Packaging: add the notebook to `extraResources` in package.json.
